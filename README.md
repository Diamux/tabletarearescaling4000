# TABLET AREA RESCALING 4000

A tablet-area and radial-follow smoothing calculator with a classic desktop-style interface.

v2 focuses on custom aspect ratios, with Diagonal Mapping, Short-Edge Bottleneck, and a legacy area-based mode. Also includes strength scaling, precision options, and click-to-copy results.

[Previous version (v1)](https://2k.lain.ch/tablet/keygen.php)

## Usage

Open the calculator, activate it with your key, enter your tablet dimensions in millimeters, and click **Calculate**. Additional options are under **Advanced Settings**.

## Activation

Keys are shared with friends. Activation is remembered automatically; **Deactivate license** clears it.

This is a small, for-fun gate, not serious DRM. If you figure out how to bypass it, congratulations.

The public build uses obfuscated JavaScript.
